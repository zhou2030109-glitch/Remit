# 项目 Skill

`skills/` 保存本次指令审阅后修订的 8 个技能及其引用、示例和已有许可证，供版本管理和跨机器使用。它们按具体任务选用；仓库开发约定仍见根目录的 `CLAUDE.md`。

- `diagnose`：可靠复现后继续修复，明确永久测试覆盖的限制。
- `to-prd`：复用已有决定，区分 PRD 草稿与已授权发布。
- `frontend-design`：沿用项目技术栈，只澄清实质未决问题，报告实际验证结果。
- `prototype`：保留待评价原型，在既有授权范围内清理或整合。
- `to-issues`：保留 HITL/AFK 类型、人工条件和拆分批准。
- `write-a-skill`：复用需求，区分普通反馈与明确审批。
- `handoff`：使用当前平台可用的安全临时文件 API。
- `caveman`：区分单次简短请求与持续模式，保留验证限制和未完成状态。

这些文件也已同步到本次使用的本机共享技能目录。后续维护若同时使用共享副本与项目副本，应同步对应目录，并保留各技能引用的文件及已有元数据。其他可选技能仅在当前环境可用且任务需要时使用。
